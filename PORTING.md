# Porting notes

`src/kwin/` is a byte-exact import of `main/src/windowing/kwin/` from the
Exiled Exchange 2 fork (feature commit `2d1e5ae5` and later fixes). It is
excluded from `tsconfig.json` and `eslint.config.mjs` until the port is done,
so the scaffold stays green. Re-include both as part of
`planning/tasks.md` task 2.1.

## Deviations from the imported source

- `KWinBridge.writeScript` adds path containment validation (resolve the
  target and require it to stay inside the script directory) before writing
  generated scripts — security hardening for a published package; behavior is
  identical for the internal fixed file names.
